# PHASE_PLAN.md

High-level epic roadmap for Web-AI / ViecConnect IT Jobs.

## Epic Order

| # | Epic          | Name                                                    | Status        |
|---|---------------|---------------------------------------------------------|---------------|
| 0 | Agent OS      | Project foundation, documentation, agent framework      | 🔄 In Progress |
| 1 | Identity      | Authentication, registration, user profile              | 📅 Planned     |
| 2 | Jobs Platform | Job listing, search, filtering, detail views            | 📅 Planned     |
| 3 | CV Upload     | CV upload, parsing, and management                      | 📅 Planned     |
| 4 | AI Foundation | AI Gateway integration and core AI services             | 📅 Planned     |
| 5 | CV Matching   | CV-to-job matching with rule-based scoring              | 📅 Planned     |
| 8 | Admin System  | Admin dashboard, user/job management, quotas            | 📅 Planned     |
| 6 | AI Interview  | AI-powered mock interview experience                    | 📅 Planned     |
| 7 | Career Chatbot| Career assistant chatbot                                | 📅 Planned     |
| 9 | Production    | Performance, deployment, monitoring                     | 📅 Planned     |

## Epic 8 Priority Note

Epic 8 (Admin System) is intentionally prioritized before Epic 6 and Epic 7 for a stronger MVP:

- User Management, Job Management, Quota Management
- AI Usage Monitoring, Import Monitoring, System Health
- Demo-ready admin dashboard early in the delivery cycle
