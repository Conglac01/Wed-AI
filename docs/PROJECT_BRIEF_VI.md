# PROJECT_BRIEF_VI.md

## Tóm Tắt Dự Án

**Tên Repository:** Web-AI
**Sản Phẩm:** ViecConnect IT Jobs
**Sản Phẩm Admin:** ViecConnect Admin

## Mô Tả

Nền tảng việc làm CNTT hiện đại ứng dụng AI, bao gồm:

- Khám Phá Việc Làm CNTT
- Tải Lên & Phân Tích CV
- Phân Tích Chất Lượng CV
- Ghép Nối CV với Việc Làm
- Phỏng Vấn AI
- Chatbot Trợ Lý Nghề Nghiệp
- Bảng Điều Khiển Admin

## Luồng MVP Chính

Đăng Ký/Đăng Nhập
→ Duyệt Việc Làm
→ Xem Chi Tiết Việc Làm
→ Tải Lên CV
→ Phân Tích CV
→ Chọn Việc Làm
→ Ghép Nối CV
→ Điểm Ghép Nối
→ Kỹ Năng Thiếu
→ Lộ Trình Học Tập
→ Bảng Điều Khiển Admin
