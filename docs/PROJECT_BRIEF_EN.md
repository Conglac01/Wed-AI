# PROJECT_BRIEF_EN.md

## Project Brief

**Repository:** Web-AI
**Product:** ViecConnect IT Jobs
**Admin Product:** ViecConnect Admin

## Description

A modern AI-powered IT career platform including:

- IT Job Discovery
- CV Upload & Parsing
- CV Quality Analysis
- CV Matching
- AI Interview
- Career Assistant Chatbot
- Admin Dashboard

## Core MVP Flow

1. Register/Login
2. Browse Jobs
3. View Job Detail
4. Upload CV
5. Parse CV
6. Select Job
7. CV Matching
8. Match Score
9. Missing Skills
10. Learning Path
11. Admin Dashboard

## Technology Stack

| Component    | Technology                       |
|-------------|----------------------------------|
| Backend     | FastAPI                          |
| User Web    | React + TypeScript + Vite + Tailwind |
| Admin Web   | React + TypeScript + Vite + Tailwind |
| Database    | PostgreSQL                       |
| AI          | DeepSeek through AI Gateway      |
